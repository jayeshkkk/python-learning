# 100 Days of Python 🐍

A daily log of my journey learning Python from the ground up — starting from 
"Hello World" and building toward functions, OOP, file handling, and beyond.

Each folder contains the code written that day, along with short notes on 
what I learned, any bugs I ran into, and how I fixed them.

## Why this repo
I'm an incoming engineering student, and I'm using this challenge to build 
consistency, get comfortable with Git/GitHub, and create a public log of my 
progress rather than just consuming a course passively.

## Structure
Each day has its own folder: `dayXX_topic/`, containing the code for that day.
